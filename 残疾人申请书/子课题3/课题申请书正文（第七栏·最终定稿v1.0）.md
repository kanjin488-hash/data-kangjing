# 七、预期研究成果

本课题以研究报告为主体、政策建议为重点，以两张路径表支撑成果转化。最终提交研究报告1份（正文不少于2万字）、政策建议1份（不少于3000字）、分旗县类型路径组合表与“障碍—路径”对应关系表各1份、技术路线图1张及成果摘要1份。测度与诊断工具、家庭问卷与访谈工具作为报告配套附件；典型案例纳入报告或附件；研究过程档案按规定内部保存。成果依据实际取得的政策资料、空间测算、入户调查、机构核查、定向访谈和专家咨询形成。目的选点不支持向内蒙古全区作统计外推，横断面资料不用于因果推断。

## （一）最终研究报告1份

形成《残疾人康复服务可及性提升路径研究》研究报告，正文不少于2万字，按“诊断—障碍机制—服务模式—提升路径”组织，主要包括：

1. **政策基准与资料来源**：按“服务对象—服务类别—责任主体—执行要求—资料留痕”梳理政策，区分现行制度要求、地方探索和本研究提出的改进方向；记录政策条款、统计口径及证据来源。
2. **调查实施与样本构成**：报告4个核心旗县共48个初级抽样单位（PSU）、约700人邀约、约593份初筛、约415人进入详细模块、约352份复合主要结局资料的规划值与实际完成值，并交代两阶段抽取概率、非应答、权重和偏差。两个补充旗县用于机构与空间核查，不并入核心旗县调查样本作比例推断。
3. **潜在空间可及性**：对康复训练和康复医疗分别呈现固定服务点的空间测算结果，说明服务容量、需求人口或代理值、路网、时间阈值、衰减参数和边界处理依据，并报告敏感性分析。模型输入不满足条件时，按预定规则降级为机构分布、服务项目可得性和最近路网时间的分项描述；不预设两个补充旗县都能完成同等深度的供需比测算。
4. **需求与服务结局**：分别报告康复训练、康复医疗和辅助器具适配的自报需求及获得情况，报告个人层面复合主要结局和三个类别特异结局的加权估计、95%置信区间与实际设计效应。“获得但自评不足”单列描述；未获得原因允许多选，分别呈现可及障碍、偏好或替代选择、需求变化等情况，不将原因比例相加为总体未获得率。
5. **五维剖面与障碍链**：综合问卷、机构资料、空间测算、政策文本和行政资料，呈现五维可及性及信息获取、数字使用等横向条件。沿“产生需求—知晓服务—作出决定—准备出发—到达机构—获得服务—持续使用”梳理典型经历；对户籍地就近评估、线上办理与基层代办、评估时限、康复巡诊排班等制度断点分别记录“证据支持”“未获支持”或“资料不足、无法判断”，不预设其普遍存在。
6. **模式条件与路径设计**：核查流动服务、远程康复和辅助器具适配服务的对象、内容、排班或流程、容量、接入条件及实际使用。仅在数据可核验时开展独立的流动或远程服务情景分析；辅助器具适配按“可获得—可负担—能适配—会使用—可维护”五环分析。依据“证据—障碍—路径”对应关系，形成分旗县类型的路径组合，并记录田野后专家意见及采纳情况。

基于概率主样本的比例及置信区间只解释为核心旗县抽样范围内的估计，不向全区外推。复合主要结局不直接比较未经需求类别数调整的旗县、人群或年度比例；分层比较与关联分析须以实际样本量、贡献PSU和复杂抽样精度为前提，并同步报告类别特异结果。村级空间结果与调查结果分表呈现，标注对应村级问卷样本量；样本量不足的单元不单独作比例判断。空间测算反映潜在可及性，不等同于个人实际获得服务。

## （二）政策建议1份

形成不少于3000字的政策建议，以“障碍—路径”对应关系表为骨架，按“问题—证据—责任主体—实施工具—适用条件—风险”组织。以下为拟核查和筛选的建议方向；只有得到具体诊断证据及实施条件支持的方向才进入最终建议：

1. **供给容量与服务半径**：以可核验的分类别服务名额、开放时段和专业人员工时支持配置论证；机构数量或挂牌情况不直接折算为服务容量。共享人员或设备承担多类服务时，核对同一时段的可用能力，避免重复计算。结合适用政策规范、本地路网、机构实际覆盖和服务对象出行经历，提出服务半径与排班调整建议。
2. **固定、流动与远程服务衔接**：依据人口分布、路网、人员配置、服务排班和数字接入条件，分别提出可实施的组织方式；不同供给形态的容量单位不可比时分项报告，不合成总分。
3. **辅助器具适配五环改进**：逐环核查目录与品类、补贴及实际自付、评估与选配、使用培训、维修维护。如证据显示评估等待影响时效敏感需求，或户籍地与居住地不一致造成申请困难，再论证流程衔接和办理方式的改进。
4. **未获得原因分环节处置**：针对确有证据的不知晓、交通、费用、陪护、等待、服务匹配、语言沟通和数字操作等障碍提出措施；将知晓服务与条件后确属自主选择的情况另行解释。各原因比例允许重叠，不相加，也不替代总体未获得比例。
5. **双语服务与服务记录**：在核实需求和执行条件后，提出蒙古语材料、双语沟通及评估和训练指令支持建议；蒙医传统疗术中的康复类项目按服务功能归入康复医疗或康复训练，疗法类型另记，不评价临床效果。建议台账分开记录需求、评估或申请状态、需求出现后的服务结局及不足情况，区分未询问、拒答、无法判断与未获得。

最终重点提炼1—2条具备证据基础和实施条件的建议，说明责任主体、步骤、资源需求及风险，并按近期可启动、中期可推进、需制度完善分类。未经本地资料证实的制度断点只列为后续核查方向，不作为已经成立的政策结论。

## （三）两张路径表、技术路线图与成果摘要

1. **分旗县类型路径组合表1份**：列明经实地核实的旗县类型、主要缺口及涉及人群、对应工具、本地可行条件、协作主体与配套风险。边境纯牧区、半农半牧、人口大县农区、山区县和资源型牧区是预设比较情境，入样旗县的具体类型属性以核查结果为准。
2. **“障碍—路径”对应关系表1份**：一行一条具体路径，列明诊断证据编号与来源、障碍机制、发生情境、实施条件和风险。填不出具体证据编号的路径不列入最终政策建议。
3. **技术路线图1张、成果摘要1份**：技术路线图展示政策基准、抽样调查、空间与机构核查、障碍机制分析、模式条件核查、专家论证和路径生成之间的关系；成果摘要概括主要发现、证据边界及可执行建议。

两张表以两轮德尔菲收敛的路径类型与候选条件为框架，经田野资料修订、田野后专家论证或书面咨询后定稿，不作综合评分或旗县排名。某一模式在入样旗县尚无实践时，仍核查其未开展的原因与缺失条件；本地缺口和可行条件有证据支持时，可形成条件性路径。缺少具体证据的路径不作为最终建议。外部案例仅作参照，须标注来源，不替代入样旗县的条件核查。

## （四）配套测度工具与调查工具

随报告整理两套可复核的配套附件：

1. **康复服务可及性测度与诊断工具1套**：包括五维指标及资料来源说明、康复训练和康复医疗的固定服务点测算规则、需求人口代理及偏误说明、边界和参数敏感性处理、容量不足时的降级规则、五维剖面与横向条件模板，以及辅助器具适配五环核查表。该工具用于本课题测算和成果复核，可供后续同类研究参考，不作为自治区统一强制标准；不设权重、不合成指数、不求解最优选址。
2. **家庭问卷与访谈工具1套（含蒙古语版）**：包括家庭问卷、机构及管理人员访谈提纲、定向样本障碍链访谈提纲、题号与跳题逻辑表、编码本、调查手册、知情同意与保密材料及双语核对记录。问卷先按服务类别判定近12个月自报需求并记录需求出现时间，再询问需求出现后的服务结局；对回答“不确定”者按预定澄清与敏感性分析规则收集必要信息，不把结局缺失编码为未获得。

工具只采集研究所必需的信息；空间定位到嘎查村、社区或可识别牧点，不采集户级坐标。“是否属人口聚居区”由研究人员结合居住点户数区间、住房分布、名录与居民点图斑等资料判定，不要求受访者直接判定统计分类。

## （五）典型案例与研究档案

在12—18名（户）具有放弃、中断、延迟或长期等待经历的定向访谈对象中，依据证据完整性和经历类型提炼障碍链案例；同时从主样本或另行寻找的符合条件家庭中选取距离较远、条件不利却持续获得服务的负例，单独注明来源。争取形成共3—5个典型案例，最终数量和类型以田野资料为准。每例交代需求出现时点、受阻或得以持续获得服务的环节、涉及主体、当时的选择、证据来源和改进所需条件。案例访谈资料仅作机制解释与路径设计材料，不作为新增的概率样本参与比例估计或主回归；负例若来自主样本，其原有问卷仍按主样本抽样设计分析。案例遵循知情同意及使用授权，经去标识化后呈现，避免披露可识别身份。

按研究会和承担单位要求提交中期进展材料；正式中期报告以具体通知为准。内部档案保存政策矩阵、两轮德尔菲记录、空间数据与模型过程文件、脱敏问卷及访谈资料、抽样和权重计算说明、数据与缺失值处理记录、双人编码及分歧记录、事实与时间线的成员核查记录、负例分析记录和专家意见采纳记录，形成可追溯的研究过程。资料实行最小必要、分级授权和身份信息与分析资料分离管理，原始敏感资料不作为公开附件传播；成果标注按立项通知或委托协议的正式项目名称及编号执行。

## （六）成果应用与解释边界

报告、政策建议与路径表供自治区及有关盟市、旗县残联和卫生健康部门在服务半径、巡诊排班、辅助器具适配流程、双语支持和服务记录改进时参考，也可为后续试点和效果验证提供待检验的方案。成果转化、公开发表或后续试点按委托方程序及相应授权办理。

本课题不承诺建设信息平台、实施真实运行试点或制定强制性标准。空间测算只解释为潜在可及性或供需空间匹配；目的选点只支持入样旗县的类型化分析，不推出全区比例；专家意见不作为服务效果证据。机构自报的业务量或满意度须注明来源，不作为独立核实的效果结果。
